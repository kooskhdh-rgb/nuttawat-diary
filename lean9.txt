หัวข้อที่้เรียน : เเก้โจทย์ใบงานเรื่อง หน้าที่ของ git
สิ่งที่ได้รับ     : ได้เรียนรู้ gitที่ยังไม่เคยเห็นในโจทย์ เช่น git --version

สิ่งที่สงสัย : ถ้าเวอร์ชั่นเกิดไม่ตรงกับเวอร์ชั่นเกิดของเพื่น(git เพื่อนเป็นเวอร์ชั่นเก่า)เราควรลบเกิตของเราเเล้วโหลดกิตที่เวอร์ชั่นตรงกับของเพื่อนไหม หรือให้เพื่อนลบกิตของเพื่อน เเล้วให้เพื่อนโหลดกิตใหม่ล่าสุด
